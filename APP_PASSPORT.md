# APP_PASSPORT — Daugavpils Top Team & Grappling Team

Правила проекта. Не нарушать в процессе разработки.

## Стек
React (Vite) · Tailwind CSS · React Router · хостинг GitHub Pages (SPA).
Бэкенд в будущем: Supabase (Auth + Database + Storage для фото).

## 1. Роли пользователей
- **Спортсмен (User):** регистрируется, видит расписание, бронирует тренировки, видит свой стаж, награды и текущий ранг.
- **Тренер/Админ (Admin — Dainis Miglāns):** управляет расписанием, отмечает посещаемость (CRM), подтверждает награды.

## 2. Регистрация и профиль
- Обязательные поля: Имя, Фамилия, Номер телефона.
- Обязательное селфи: фото загружается при регистрации для быстрой визуальной идентификации учеников тренером.
- Спортивное портфолио: стаж занятий, история соревнований, медали.

## 3. Клубная геймификация (система рангов)
**Только для грепплинга.** У MMA / K1 рангов пока нет.

Ранг повышается автоматически по числу посещённых тренировок.
Пересчёт стажа: **1 год ≈ 90 тренировок** (2 раза в неделю × 45 недель активного сезона).

| Ранг | Стаж | Тренировок |
|---|---|---|
| 1. Юный падаван | до 1 года | 0+ |
| 2. Тролль | 1–3 года | 90+ |
| 3. Матёрый тролль | 3–4 года | 270+ |
| 4. Ронин тролль | 4–7 лет | 360+ |
| 5. Старый тролль | 7+ лет | 630+ |

Тренер может вручную повысить или понизить ранг (ручной ранг важнее автоматического) и вернуть автоматический режим.

## 5. Мобильные приложения
Цель — Google Play и App Store. **Путь: PWA + Capacitor**, без переписывания на React Native.
- PWA: `vite-plugin-pwa` (манифест, сервис-воркер, иконки в `public/`).
- Capacitor: `capacitor.config.json`, appId `lv.daugavpilstopteam.app` (после публикации в сторах менять нельзя).
- Нативные функции (камера и т.п.) — через плагины `@capacitor/*`, только при `Capacitor.isNativePlatform()`.
- **Обязательно до публикации в сторах:** удаление аккаунта из приложения (требование Google Play и Apple),
  страница «Политика конфиденциальности» (селфи, телефон, вес — личные данные; детские группы),
  анкета Data safety (Google) / App Privacy (Apple).
- Google Play: новый личный аккаунт разработчика — закрытый тест (12+ тестеров, 14 дней) до публичного релиза.
- Обновления: изменения веб-части без пересборки — через live-update (Capgo / Capawesome);
  новые нативные плагины и разрешения — только новой версией в сторе.

   Секретные ключи Stripe — только на сервере (Supabase Edge Functions), никогда во фронтенде.
3. Магазин мерча GERA (Украина)
4. Лидерборд
5. QR-чекин
6. Трекинг веса (`profiles.current_weight`)
7. Электронный дневник
8. База видеоуроков
9. **ИИ-помощник для учеников** — вопросы о расписании, ценах, рангах; позже советы по весу и дневнику

Правила для ИИ: ключ Claude API — только на сервере (Supabase Edge Function); агент видит только данные,
разрешённые текущему пользователю (те же RLS); лимит запросов в день на человека; без медицинских советов
и советов по сгонке веса, для детских аккаунтов — ограниченный режим.

### Идеи тренера (бэклог, ноябрь 2026)
- **Прогресс и личные рекорды:** графики веса тела, рабочих весов и объёмов; «карта тела» — какие зоны нагружались (из дневника).
- **Носимые устройства:** пульс, зоны, шаги из Apple Watch / Garmin / Fitbit. Только в нативной сборке (Capacitor + HealthKit / Health Connect); в браузере недоступно.
- **Программы и ИИ-тренер:** планы под цель (похудение, масса, выносливость), подстраиваются под дневник. Доступ — только с оплаченным абонементом (40/45 €). Правила ИИ — см. выше (без медицинских советов и сгонки веса, детям — ограниченный режим).
- **Социальное:** лента активности друзей, таблица лидеров, челленджи между учениками, «поделиться результатом». Приватность — как в идее Даниила (можно скрыть себя).

### Идеи учеников (бэклог, ноябрь 2026)
- **Даниил:** подтверждение пароля при регистрации (поле «Повторите пароль»).
- **Даниил:** аватар из галереи, а не только селфи с камеры (выбор «Камера / Галерея», тот же сжатый JPEG в приватном бакете).
- **Даниил:** аватарки в списке оценок/рейтинге партнёров (signed URL, как в CRM).
- **Даниил:** приватность профиля (как в Smoothcomp) — ученик может скрыть свои данные от других учеников; тренер видит всё.
- **Артур:** взрослым новичкам страшно идти «в одиночку». Уже есть «Позвать друга» (слой 12) — развить:
  приветственный статус «Новичок» на первые тренировки, видимый партнёрам, и блок «Приходи с напарником» на главной.
