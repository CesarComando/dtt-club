# Помощник «Спросить» (Claude) — как включить

Ученики нажимают **«Спросить»** (кнопка справа внизу) и получают ответ ИИ по данным клуба.
Помощник видит: факты клуба (вкладка тренера «Помощник»), расписание, цены, ближайшие занятия,
а также абонемент и записи **только самого спрашивающего**. Сам он ничего не меняет.

## Включить (один раз)

1. **SQL.** Supabase → SQL Editor → выполнить `supabase/layer32_assistant.sql`.
2. **Ключ Claude API.** console.anthropic.com → API Keys → Create Key. Пополнить баланс (Billing), хватит 5–10 €.
3. **Секрет.** Supabase → Edge Functions → Secrets → добавить `ANTHROPIC_API_KEY` = ключ из п. 2.
   Необязательно: `ANTHROPIC_MODEL` (по умолчанию `claude-haiku-5-5`), `ASK_DAILY_LIMIT` (по умолчанию 30 вопросов в день на человека).
4. **Функция.** В папке проекта: `npx supabase functions deploy ask-club`.
5. **Приложение.** `npm run deploy`.

Проверка: войти учеником → «Спросить» → «До какого числа мой абонемент?».

## Сколько стоит
Один вопрос — примерно 2–3 тыс. токенов (контекст клуба + ответ). На модели Haiku это доли цента;
при сотне вопросов в месяц — несколько евро. Лимит в день защищает от неожиданных счетов.
В console.anthropic.com → Limits можно поставить месячный лимит расходов.

## Что править
- Тексты помощника — в приложении: Тренер → «Помощник» → Сохранить (сразу, без деплоя).
- Поведение (правила ответа) — константа `SYSTEM` в `supabase/functions/ask-club/index.ts`.
